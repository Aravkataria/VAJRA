Formal Verification Mechanics

How Model 3 filters neural false alarms and mathematically proves software safety.

First-Order Z3 SMT Prover

Transforms taint propagation paths into first-order logic formulas over AST variables. A patch is only approved when Z3 proves that exploit reachability conditions are strictly unsatisfiable (UNSAT).

Z3 SMT Solver · UNSAT Guarantees

Sanitizer Barrier Verification

Inspects candidates flagged by Model 1 for active parameterization boundaries (such as PreparedStatement, ast.literal_eval, and shlex.quote), filtering out false alarms on safe wrappers.

False Alarm Filter · 99.4% Accuracy

Unified Code Property Graph (CPG)

Synthesizes Abstract Syntax Trees (AST), Control Flow Graphs (CFG), and Program Dependence Graphs (PDG) into a single queryable graph database traversing cross-function and cross-file dependencies up to 32 hops.

Interprocedural · 32 Hops Deep
